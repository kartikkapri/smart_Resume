PROJECT OVERVIEW:
-----------------
Smart Resume Analyzer ek AI-powered web application hai jo job seekers ko unke resume 
analyze karne, skill gaps identify karne, personalized learning roadmaps generate karne, 
aur relevant job recommendations provide karne mein help karta hai.

An AI-powered web application that analyzes resumes, identifies skill gaps, generates 
personalized learning roadmaps, and provides job recommendations based on target roles.


KEY FEATURES:
-------------
1. 📄 PDF Resume Analysis - Automatic skill extraction from uploaded resumes
2. 🎯 Role-Based Skill Gap Analysis - SDE, AI-ML, DevOps, Data Science roles ke liye
3. 🗺️ AI-Generated Learning Roadmaps - 8-week personalized learning paths with resources
4. 💼 Job Recommendations - Skills ke basis par job matching with salary information
5. 📊 Interactive Dashboard - Analysis history aur progress tracking
6. 🌓 Dark/Light Mode - User preference ke liye theme switching
7. 📈 Visual Analytics - Charts aur graphs for better insights
8. 🔍 Job Description Comparison - Resume ko specific JD se compare karne ke liye

API ENDPOINTS:
--------------
1. POST /upload-resume
   - Upload PDF resume and extract text + skills
   - Input: PDF file
   - Output: Extracted text and skills list

2. POST /analyze
   - Complete resume analysis with skill gap
   - Input: PDF file, target_role
   - Output: Matched skills, missing skills, readiness score

3. POST /analyze-gap
   - Analyze skill gap for specific role
   - Input: Extracted skills, target role
   - Output: Gap analysis with percentages

4. POST /generate-roadmap
   - Generate 8-week learning roadmap using AI
   - Input: Missing skills, target role
   - Output: Week-by-week learning plan with resources

5. POST /compare-jd
   - Compare resume with job description
   - Input: Resume skills, job description text
   - Output: Match percentage, matched/missing skills

6. POST /job-recommendations
   - Get personalized job recommendations
   - Input: User skills, target role
   - Output: List of matching jobs with details

ALGORITHMS & LOGIC:
-------------------

1. Skill Extraction Algorithm:
   - Text preprocessing (lowercase conversion)
   - Regex pattern matching with word boundaries
   - Alias mapping for skill variations
   - Set-based deduplication

2. Skill Gap Analysis:
   - Set intersection for matched skills
   - Set difference for missing skills
   - Percentage calculation: (matched/required) × 100
   - Skill normalization for accurate comparison

3. Job Matching Algorithm:
   - Skill overlap calculation
   - Match score: (common_skills/required_skills) × 100
   - Sorting by match score and experience level
   - Top 6 recommendations returned

HOW TO RUN:
-----------
Backend:
1. cd app
2. pip install -r requirements.txt
3. Create .env file with OPENAI_API_KEY
4. uvicorn app.main:app --reload
5. Server runs on http://localhost:8000

Frontend:
1. cd frontend
2. npm install
3. npm run dev
4. App runs on http://localhost:5173
