INTERVIEW TALKING POINTS:
--------------------------------------------------------------------------------

Q: Tell me about this project
A: "I built an AI-powered resume analyzer that helps job seekers identify their 
skill gaps and provides personalized learning paths. It uses React for the 
frontend, FastAPI for the backend, and integrates OpenAI's API for generating 
intelligent roadmaps. The system can extract skills from PDF resumes, compare 
them with role requirements, and recommend relevant jobs from a database of 40+ 
listings."

Q: What was the biggest challenge?
A: "The biggest challenge was accurately extracting skills from unstructured 
PDF text. Resumes come in various formats, so I implemented a robust regex-based 
pattern matching system with skill aliases to handle variations like 'React', 
'ReactJS', and 'React.js'. I also added normalization logic to avoid duplicates."

Q: How did you integrate AI?
A: "I integrated OpenAI's GPT-3.5 API to generate personalized learning roadmaps. 
I designed a specific prompt that returns structured JSON with week-by-week 
learning plans and resources. I also implemented a fallback mock roadmap system 
in case the API is unavailable, ensuring the app always works."

Q: What about scalability?
A: "The architecture is modular and scalable. The backend uses FastAPI which is 
async by default, making it fast and efficient. The frontend uses React with 
proper state management and lazy loading. I also implemented caching for analysis 
history using localStorage to reduce API calls."

Q: How did you handle different roles?
A: "I created a role-based skill mapping system where each role (SDE, AI-ML, 
DevOps, Data Science) has predefined required skills. The analyzer compares user 
skills with role requirements using set operations and calculates a readiness 
percentage. This makes it easy to add new roles in the future."
